# 2026-11-27 — Rework R1: US-L0-03, -10, -11 follow spec gate-1.5 (paths, lock outcomes, names)

- `notecraft-store`: lock, holder record and journal move to `.local/` (`LOCAL_DIR`, `LOCK_FILE`,
  `LOCK_RECORD`, `JOURNAL_DIR`); `.gitignore` is `.cache/` and `.local/`; `is_reserved` covers `.local`;
  `create` writes `.local/lock`. `Holder` is `{process, pid, host, since}` (`host` clipped to 255 bytes,
  `since` only as RFC 3339, `process` only `app`/`cli`/`mcp`). `ReadOnlyReason::NoLock`; reasons are
  camelCase (`newerFormat`, `noLock`). An unreadable page counts as not trashed.
- `notecraft-engine`: `Session::set_process` and `Process`; `workspace.open` tries the lock once and
  never waits (busy: opens read-write without recovery; no lock possible: read-only `noLock`);
  `staleLock` is a boolean; `readOnlyReason` is left out when writable; `disabled`/`locked` carries
  `details.holder` and no `cause`; a lock the file system cannot give makes the session read-only
  (`read_only`, `details.reason: "noLock"`); `workspace.create` takes a blank name as absent and stores a
  given one trimmed.
- The journal keeps its ADR 0006 mechanics at its new path; the forward-replay journal is R2.
- Decisions: [ADR 0008](../adr/0008-transactions-and-lock-follow-gate-1-5.md).

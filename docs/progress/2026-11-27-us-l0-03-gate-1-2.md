# 2026-11-27 — US-L0-03 rework for spec gate-1.2 (D-43)

- `notecraft-model`: `Workspace.name` is an `Option` (absent or unusable means the default name).
- `notecraft-store`: `Project::locate` (project folder or its `notecraft/`), `Project::default_name`
  and `DEFAULT_NAME`; no `databases/` folder; a missing project folder is `NotFound`; only `format` and
  `id` are required in the manifest and unknown keys are kept on rewrite; `Workspace::project_dir`
  and `name`; `count_items` gives pages, databases and rows and leaves the trash out; the staging
  sweep works in the located project, not in the parent of a `notecraft` link.
- `notecraft-engine`: `workspace.create`, `open` and `info` report the project folder in `path`;
  `open` accepts `notecraft/`; a missing project is `not_found`; `info` gains `rows`.
- Decisions: [ADR 0005](../adr/0005-workspace-on-disk.md) (amended).

# 2026-11-27 — US-L0-11: workspace lock and single engine

- `notecraft-store`: `Workspace::lock` and `Workspace::holder`, `WriteLock` (released on drop; removes the record,
  keeps the empty lock file), `Holder` (the advisory record codec), `LockError`. The lock is std `File::try_lock` on
  `.cache/lock`; no new dependency and no `unsafe`. On wasm the lock is `Unsupported` and no timer is used.
- `notecraft-engine`: the lock around every mutating command, undo and redo; recovery under the lock
  whenever a journal head exists; the sweep when a stale lock is found; `workspace.open` locks before
  recovery and returns `staleLock`; `Session::set_lock_wait`, `LOCK_WAIT`; catalog row F-CMD-11 now
  names `workspace.open`.
- A refused lock is `disabled` with `details.reason: "locked"`, `cause` and `holder`; a lock path that
  cannot be used is `io` with reason `lock`.
- Decisions: [ADR 0007](../adr/0007-workspace-write-lock.md) (accepted).
- Round 3: `.cache/lock` is persistent (written empty by `workspace.create`, never deleted); release removes only `.cache/lock.json`, then unlocks. Windows `PermissionDenied` is `io` at once; error 32 is retried to the deadline, then `io`.
